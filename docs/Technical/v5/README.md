# Falcon Dash v5 Working Contracts

> **Document class: future working contract.** These files describe approved direction that is not
> yet fully implemented. Current behavior remains documented in the parent `Technical/` directory.

Falcon Dash v5 combines the desktop-web overhaul with contextual OpenClaw conversations. The
visual authority remains [DESIGN.md](../../DESIGN.md); this directory records the product and domain
contracts that the interface must represent truthfully.

## Working contracts

- [work-domain-decisions.md](work-domain-decisions.md) — accepted Work-domain decisions and open
  questions from the database-first audit tracked in
  [#363](https://github.com/fdsouvenir/falcon-dash/issues/363)
- [task-aggregate.md](task-aggregate.md) — synthesized target Task ownership, persistence,
  lifecycle, command, projection, and migration contract

The retained v3 contracts remain available in [../v3/](../v3/README.md) as the approval and
implementation history. A v5 working contract supersedes a v3 semantic only where it says so
explicitly.
